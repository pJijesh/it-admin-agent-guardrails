## [1.0.0] - 2026-11-11

### Added

- The it-admin-guardrails skill: read first, dry run by default, named targets, least privilege, approval gates, evidence.
- A zero-dependency checker with 26 rules for PowerShell administration scripts, with per-line and per-file overrides that need a reason.
- A safe script template, and worked unsafe and safe fictional examples.
- Installers for Claude Code, Codex, OpenCode and Cursor, with generated adapters.
- Community files, citation metadata and a Dependabot configuration.
